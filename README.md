# Amazon Kiro on AWS

Student lab materials for the **Amazon Kiro on AWS** course.

## Labs

| Lab | Name | Description |
|-----|------|-------------|
| Lab 1 | [Getting Started with Kiro](labs/lab1/) | Kiro setup, workspace configuration, first spec-driven project |
| Lab 2 | [Spec-Driven Development](labs/lab2/) | Requirements → specs → implementation with Kiro steering |
| Lab 3 | [Hooks and Automation](labs/lab3/) | Lifecycle hooks, automated testing, CI/CD integration |
| Lab 4 | [Enterprise Patterns](labs/lab4/) | Team workflows, code review, architecture documentation |

## Prerequisites

- AWS account with Amazon Kiro access
- Modern web browser (Chrome, Firefox, or Edge)
- GitHub account for repository integration
- Basic programming experience (JavaScript/TypeScript or Python)
