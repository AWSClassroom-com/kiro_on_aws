# Product

Food Tracker is a single-page application for tracking food inventory and nutritional information. Users can add food items with details like quantity, unit, calories, macros (protein/carbs/fat), category, and expiration date. Items are listed in reverse-chronological order and can be deleted individually.

The app is a demo/starter project built on AWS Amplify Gen 2, intended to showcase a modern React + cloud-backend stack. Authentication is intentionally minimal (public API key) — production use would require Cognito.
