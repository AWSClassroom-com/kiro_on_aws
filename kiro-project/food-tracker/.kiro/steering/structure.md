# Project Structure

## Root Level Organization

```
├── src/                    # Source code
├── public/                 # Static assets
├── drizzle/               # Database migrations (generated)
├── .kiro/                 # Kiro IDE configuration
├── node_modules/          # Dependencies
└── config files           # Various config files
```

## Source Code Structure (`src/`)

```
src/
├── components/            # Reusable React components
├── routes/               # File-based routing (TanStack Router)
│   ├── __root.tsx        # Root layout component
│   ├── index.tsx         # Home page route
│   └── demo/             # Demo routes
├── db/                   # Database layer
│   ├── schema.ts         # Drizzle schema definitions
│   └── index.ts          # Database connection setup
├── data/                 # Static data and fixtures
├── router.tsx            # Router configuration
├── routeTree.gen.ts      # Generated route tree (auto-generated)
└── styles.css            # Global styles
```

## Key Conventions

### Routing

- **File-based routing** using TanStack Router
- Route files in `src/routes/` directory
- `__root.tsx` defines the root layout
- `routeTree.gen.ts` is auto-generated, never edit manually

### Database

- All database schemas in `src/db/schema.ts`
- Database connection configured in `src/db/index.ts`
- Use Drizzle ORM for all database operations
- Migrations stored in `drizzle/` directory (auto-generated)

### Components

- Reusable components in `src/components/`
- Use TypeScript with React functional components
- Follow React 19 patterns and hooks

### Styling

- Tailwind CSS for all styling
- Global styles in `src/styles.css`
- Component-specific styles using Tailwind classes

### Path Aliases

- `@/*` maps to `./src/*` for clean imports
- Example: `import Header from '@/components/Header'`

## Generated Files (Do Not Edit)

- `src/routeTree.gen.ts` - Auto-generated by TanStack Router
- `drizzle/` directory contents - Generated by Drizzle Kit
- Files excluded from Biome formatting in `biome.json`

## Environment Files

- `.env.local` - Local environment variables (not committed)
- Contains `DATABASE_URL` for PostgreSQL connection
