# Project Structure

```
amplify/                        # Amplify Gen 2 backend (separate TS project)
├── backend.ts                  # defineBackend entry point
├── data/resource.ts            # FoodItem data model + auth config
├── package.json                # Amplify-specific dependencies
└── tsconfig.json               # Separate TS config for backend

src/                            # Frontend application
├── components/                 # Shared React components
│   └── Header.tsx              # App header + slide-out nav drawer
├── lib/
│   └── amplify-client.ts       # Amplify.configure() + typed `client` export
├── routes/                     # File-based routes (TanStack Router)
│   ├── __root.tsx              # Root layout — renders <Header> + <Outlet>
│   ├── index.tsx               # Landing/home page (/)
│   └── food-tracker.tsx        # Main feature page (/food-tracker)
├── main.tsx                    # App entry point — mounts <RouterProvider>
├── router.tsx                  # createRouter() with routeTree
├── routeTree.gen.ts            # AUTO-GENERATED — do not edit
└── styles.css                  # Global styles (excluded from Biome)

scripts/
├── sandbox.ts                  # Starts Amplify sandbox + runs seed on first deploy
└── seed.ts                     # Seeds FoodItem table with 30 sample items

public/                         # Static assets served as-is
amplify_outputs.json            # Generated by sandbox — gitignored, required at runtime
amplify.yml                     # Amplify Hosting CI/CD build spec
index.html                      # SPA shell (root element: #app)
vite.config.ts                  # Vite config with plugins
biome.json                      # Linter/formatter config
tsconfig.json                   # Frontend TS config (excludes amplify/)
```

## Key Conventions

**Routing**: Add new pages as files in `src/routes/`. The TanStack Router Vite plugin auto-generates `routeTree.gen.ts`. Each route file exports a `Route` constant created with `createFileRoute`.

**Data access**: Import `client` from `@/lib/amplify-client` to interact with the Amplify data API. Types come from `Schema` in `amplify/data/resource.ts`.

**Components**: Shared/reusable components go in `src/components/`. Route-specific sub-components can be defined inline within the route file (as seen in `food-tracker.tsx`).

**Styling**: Use Tailwind utility classes directly. The design uses a dark slate theme (`slate-800/900` backgrounds, `white`/`gray-*` text, `emerald`/`cyan` accents).

**Validation**: Use Zod schemas for all form inputs. Define the schema at the top of the file, infer the type with `z.infer<typeof schema>`.

**Backend changes**: Modify `amplify/data/resource.ts` to update the data model. The sandbox watcher will auto-redeploy on save.
