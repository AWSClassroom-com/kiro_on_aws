# Tech Stack

## Frontend
- **React 19** with TypeScript (strict mode)
- **TanStack Router v1** — file-based routing, auto code splitting via Vite plugin
- **Tailwind CSS v4** — via `@tailwindcss/vite` plugin (no config file, CSS-first)
- **Zod v4** — form and data validation
- **Lucide React** — icon library

## Backend
- **AWS Amplify Gen 2** — infrastructure-as-code in TypeScript
- **AppSync** — auto-generated GraphQL API
- **DynamoDB** — data store (via Amplify `a.model()`)
- **API Key auth** — public, 30-day expiry (defined in `amplify/data/resource.ts`)

## Build & Tooling
- **Vite** — dev server and bundler, outputs to `dist/`
- **Biome** — linter and formatter (replaces ESLint + Prettier)
  - Indent style: tabs
  - Quote style: double
  - Excludes: `src/routeTree.gen.ts`, `src/styles.css`
- **Vitest** — test runner with jsdom + @testing-library/react
- **tsx** — runs TypeScript scripts directly (used for sandbox/seed scripts)

## Path Aliases
- `@/*` maps to `./src/*` (configured in `tsconfig.json` and `vite-tsconfig-paths`)

## Common Commands

```bash
npm run dev                   # Vite dev server on port 3000
npm run build                 # Production build → dist/
npm run serve                 # Preview production build
npm test                      # Run Vitest (single run, no watch)
npm run lint                  # Biome lint
npm run format                # Biome format
npm run check                 # Biome lint + format check combined

npm run amplify:sandbox       # Start cloud sandbox + file watcher + auto-seed
npm run amplify:sandbox:bare  # Start sandbox without auto-seed
npm run amplify:sandbox:delete # Tear down sandbox resources
npm run seed                  # Manually re-seed FoodItem table (30 sample items)
```

## Important Notes
- `amplify_outputs.json` is generated by the sandbox and is gitignored. The frontend won't start without it — always run `amplify:sandbox` at least once before `npm run dev`.
- `src/routeTree.gen.ts` is auto-generated by the TanStack Router Vite plugin — never edit it manually.
- The Amplify backend is defined entirely in `amplify/` and is separate from the frontend TypeScript config (excluded from root `tsconfig.json`).
