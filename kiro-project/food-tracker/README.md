# Food Tracker (AWS Amplify Edition)

A modern food-tracking SPA built with React 19, TanStack Router, and AWS Amplify Gen 2 (AppSync + DynamoDB). Track food items, nutritional info, and expiration dates with a dark-themed UI — deployed end-to-end on AWS Amplify Hosting.

## Tech Stack

### Frontend

- **React 19** + **TanStack Router** (SPA, file-based routing)
- **TypeScript** (strict)
- **Tailwind CSS v4**
- **Vite** (build/dev server)
- **Zod** (form validation)

### Backend (AWS Amplify Gen 2)

- **AppSync** (GraphQL API, auto-generated)
- **DynamoDB** (data store)
- **API Key auth** (public, 30-day expiry — swap to Cognito for real apps)

## Prerequisites

- Node.js 20+
- npm (bundled with Node)
- AWS account with credentials configured (`aws configure` or `~/.aws/credentials`)

## Local Development

1. **Install dependencies**

   ```bash
   npm install
   ```

2. **Start the Amplify sandbox** (provisions a per-developer cloud backend, writes `amplify_outputs.json`, **and auto-seeds the FoodItem table on first deploy**)

   ```bash
   npm run amplify:sandbox
   ```

   Leave this terminal open — it watches `amplify/` for changes and redeploys automatically. The seed runs once per `npm run amplify:sandbox` invocation; if you want to reseed later, run `npm run seed` manually. To skip auto-seed entirely, use `npm run amplify:sandbox:bare`.

3. **Start the Vite dev server** (in a second terminal)

   ```bash
   npm run dev
   ```

   Visit http://localhost:3000.

4. **Tear down the sandbox** when finished

   ```bash
   npm run amplify:sandbox:delete
   ```

> **Note:** `amplify_outputs.json` is generated by the sandbox and is gitignored. The frontend won't compile until it exists, so always run `npm run amplify:sandbox` (at least once) before `npm run dev`.

## Deploying to AWS Amplify Hosting

1. Push this repo to GitHub/GitLab/Bitbucket/CodeCommit.
2. In the AWS Console, open **Amplify → Create new app → Host web app**.
3. Connect your repo and pick the branch.
4. Amplify auto-detects `amplify.yml`. The pipeline will:
   - Run `npx ampx pipeline-deploy` to provision/update the backend (AppSync, DynamoDB, API key).
   - Run `npm run build` and publish `dist/` to the CDN.
5. **Add an SPA rewrite rule** so client-side routes work on refresh. In Amplify Console → App settings → Rewrites and redirects, add:

   ```
   Source:  </^[^.]+$|\.(?!(css|gif|ico|jpg|js|png|txt|svg|woff|woff2|ttf|map|json|webp)$)([^.]+$)/>
   Target:  /index.html
   Type:    200 (Rewrite)
   ```

That's it — every push to the connected branch redeploys both backend and frontend.

## Data Model

Defined in `amplify/data/resource.ts`:

| Field            | Type      | Notes              |
| ---------------- | --------- | ------------------ |
| `id`             | string    | auto (uuid)        |
| `name`           | string    | required           |
| `description`    | string    | optional           |
| `category`       | string    | optional           |
| `quantity`       | integer   | optional           |
| `unit`           | string    | optional           |
| `calories`       | integer   | optional           |
| `protein`        | float     | optional           |
| `carbs`          | float     | optional           |
| `fat`            | float     | optional           |
| `expirationDate` | datetime  | ISO-8601 string    |
| `addedAt`        | datetime  | required, user-controlled (form sets it to now; seed varies it for demo) |
| `createdAt`      | datetime  | auto-managed       |
| `updatedAt`      | datetime  | auto-managed       |

Auth: `allow.publicApiKey()` — anyone with the API key (embedded in `amplify_outputs.json`) can read/write. For production, replace with Cognito user-pool auth.
