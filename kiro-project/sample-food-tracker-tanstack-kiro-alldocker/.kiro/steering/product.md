# Product Overview

This is a food tracking application that allows users to manage their food items with full CRUD operations (Create, Read, Update, Delete). The app is built as a modern full-stack web application using TanStack Start framework.

## Core Features

- Add new food items
- View existing food items
- Edit food item details
- Delete food items
- List all food items

## Target Users

Users who want to track and manage their food consumption or inventory in a simple, intuitive web interface.

## Key Characteristics

- Full-stack React application with server-side rendering
- Type-safe from database to UI
- Modern, responsive design with Tailwind CSS
- Real-time data management with Drizzle ORM
